# v1.53.0 — SCITT witness anchor + persistent trail + prior-approval learning

**SCITT anchor replaces OpenTimestamps.** New `vaara.audit.scitt_anchor` module appends receipt digests to a Merkle transparency log and records inclusion proofs. Verifiable by recomputation — no key, no third party. Aligned with IETF draft -06.

**Persistent trail by default.** `@vaara.govern` now auto-creates `~/.vaara/trail/audit.db` via SQLite — no config needed. All actions survive restarts.

**Prior-approval auto-allow.** Once an operator approves an escalated action, the pipeline remembers. Same agent + tool_name next time? Auto-allowed with a trail note. Learning without policy files.

**OpenCode governance.** `vaara init` now detects and configures governance for OpenCode alongside Claude Code, Cursor, and Windsurf.

Full details in CHANGELOG.md.
